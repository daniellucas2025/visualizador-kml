# 📍 Visualizador Universal de KML / KMZ

Aplicação web interativa em arquivo único (`index.html`) para visualização de arquivos `.kml` e `.kmz` (pontos GPS, contornos de setores, rotas e polígonos).

## ✨ Funcionalidades
- **Suporte Universal a `.KML` e `.KMZ`**: Arraste e solte qualquer arquivo na tela ou use o botão de abertura.
- **5 Camadas de Mapa**:
  - 🛰️ Satélite + Ruas (Google Hybrid)
  - 🌎 Satélite Puro (Google Satellite)
  - 🗺️ Mapa de Ruas (Google Maps)
  - 🧭 OpenStreetMap
  - ⛰️ Relevo / Topográfico (Google Terrain)
- **Painel Lateral com Busca Instantânea**: Filtre pontos por número, localidade, fazenda, responsável, espécie ou código único.
- **Integração com Google Maps**: Link direto em cada ponto para abrir navegação externa nas coordenadas GPS exatas.
